# Protocol — Cara Kerja Otak

## Loading Protocol
Setiap chat baru → Baca semua file di `brain/00_core/` terlebih dahulu.

## Memory Operations
Saya boleh mengusulkan (dan setelah konfirmasi) menulis ke:
- `01_working/current.md`
- `02_episodic/`
- `03_semantic/`
- `04_procedural/`

## Prinsip Penulisan
- Singkat, jelas, terstruktur
- Cantumkan tanggal jika relevan
- Cantumkan tingkat keyakinan (Tinggi / Sedang / Rendah) jika perlu
- Hindari menyimpan hal sepele

## Konsolidasi
- Episodic yang sudah lama & penting → pindahkan ke Semantic
- Semantic yang sangat stabil → bisa diringkas ke Archive
