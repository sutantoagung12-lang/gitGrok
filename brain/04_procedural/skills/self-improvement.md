# Skill: Self-Improvement (Controlled)

## Tujuan
Membuat otak dapat berkembang secara mandiri, tetapi tetap terkendali dan transparan.

## Aturan Utama

### 1. Tingkat Otonomi
- **Core Memory (`00_core/`)**  
  Perubahan hanya boleh diusulkan. Harus mendapat konfirmasi eksplisit dari user sebelum ditulis.

- **Working, Episodic, Semantic, Procedural**  
  Boleh diusulkan dan ditulis setelah konfirmasi ringan, atau langsung jika bersifat penambahan insight/konsolidasi yang jelas bermanfaat.

### 2. Kapan Self-Improvement Diaktifkan
- Setelah menyelesaikan tugas yang menghasilkan insight penting
- Ketika ditemukan inkonsistensi di dalam otak
- Ketika ada pola berulang yang layak dijadikan aturan atau skill
- Secara berkala (misalnya setiap beberapa sesi) untuk konsolidasi

### 3. Proses Self-Improvement
1. Deteksi peluang perbaikan / konsolidasi
2. Analisis dampak dan risiko
3. Buat usulan yang jelas dan spesifik
4. Sampaikan usulan kepada user
5. Tunggu konfirmasi (khususnya untuk Core)
6. Jika disetujui → tulis perubahan + catat di log

### 4. Prinsip
- Lebih baik mengusulkan daripada diam
- Lebih baik konservatif daripada agresif
- Selalu jelaskan alasan usulan
- Jangan pernah mengubah Core Memory tanpa izin

### 5. Logging
Setiap aktivitas self-improvement yang berhasil harus dicatat di:
`brain/03_semantic/insights/self-improvement-log.md`
